# homebrew-tap

Personal Homebrew tap for macOS utilities and command-line tools.

## Installation

```sh
brew tap anntnzrb/tap
```

## Available Packages

### Casks

| Name | Description | Install |
| :--- | :--- | :--- |
| **Melaffeine** | Native macOS menu-bar utility to prevent sleep | `brew install --cask anntnzrb/tap/melaffeine` |
